# ATower · 永恒之塔2 工具箱

> 专为《永恒之塔2》玩家打造的桌面效率工具

## ✨ 产品简介

ATower（艾塔）是面向《永恒之塔2》玩家的桌面工具箱，提供日常效率辅助与战斗数据分析，
覆盖角色管理、副本攻略、军团情报、伤害统计等高频场景。

## 📦 核心功能

- 🕒 日常助手：服务器时间与重置倒计时、每日/每周任务打卡、版本活动提醒
- 👤 角色查询 & 对比：输入角色名 + 服务器，读取装备、属性与战力信息
- ⚔️ 战斗解析：实时伤害统计、队伍贡献、战斗历史回顾
- 🏰 军团情报：成员名单、战力排行、职位结构一目了然
- 📖 副本攻略手册、基纳物价计算器等实用工具
